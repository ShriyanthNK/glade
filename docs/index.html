He only shows up when it matters

        

          
Waits before bothering you
Five seconds after a permission prompt or a finished task. If you reply first, he never appears. Both delays are adjustable.

          
Gets impatient
Taps his foot at first, holds up a ? sign after a minute and a !! sign after two. After three he gives up and leaves.

          
Follows you across monitors
He shows up on whichever screen your mouse is on, above full-screen apps, on every Space.

          
Never steals focus
You can click straight through everything except Mochi and his bubble. Click him to jump to your terminal, VS Code, iTerm or Ghostty.

          
Easy to silence
claude-buddy snooze 30 mutes him for half an hour. The x on the bubble dismisses just this one.

          
Stays on your machine
Claude Code hooks hand events to a small app over a local socket. No network, no accounts, no telemetry.

        

      

    


    

      
Four moods, all drawn by hand in code

      
Every frame is generated from a 32 by 32 pixel grid. These are running live.

      

        

        

        

        

      

    


    

      

        
Install in a minute

        

          
You need macOS 13 or later, jq, and a Swift toolchain (Xcode or the Command Line Tools). The installer builds the app, adds four hooks to ~/.claude/settings.json, and backs that file up first.

          

            

git clone https://github.com/ShriyanthNK/claude-buddy.git
cd claude-buddy
./install.sh
claude-buddy test

          

          

            
Build
The script compiles the app into ~/.claude-buddy. No Dock icon, no login item.

            
Hook
It merges its hooks with your existing settings. Anything already there stays.

            
Say hi
claude-buddy test shows Mochi right away. Restart Claude Code sessions to pick up the hooks.

          

        

      

    


    

      

        
Questions

        

          
How do I remove it?
Run ./uninstall.sh. It takes out only its own hooks, deletes the app, and leaves a backup of your settings.

          
What if I don't want him on screen for a while?
claude-buddy snooze 30 for thirty minutes, snooze forever for good, snooze clear to bring him back.

          
Can I change the delays or turn on a chime?
claude-buddy delays 5 5 sets the waiting and done delays in seconds. claude-buddy chime on adds a soft sound.

          
Does it work with several Claude Code sessions?
Yes. Events are matched by session, so replying in one terminal doesn't hide the buddy for another.

          
Is Mochi Claude's mascot?
No. He's an original character and this is an independent open source project, not an Anthropic product.
