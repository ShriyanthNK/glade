# UX profile: Glade (macOS app window)

Read by the VectorLab UX audit. Anything not listed here follows the catalog hard rules.

- **Aesthetic:** playful pixel art in a native window. Dark plum, cream text, one yellow accent, Hoot the owl.
- **Platform:** macOS pointer UI. **Hit targets:** 24pt minimum (WCAG 2.2 target size), most controls 26-32pt; the catalog's
  44pt is a touch figure and does not apply to a Mac window with a pointer. **Text floor:** 12pt; body 14-16pt.
- **Typefaces (SIL OFL, bundled in Resources/Fonts):** Bricolage Grotesque (display, titles, sidebar), Pixelify Sans
  (small pixel labels and buttons), JetBrains Mono (Hoot's voice: bubbles, numbers). Body copy uses the system font.

## Deliberate exceptions to the catalog

1. **Hard offset pixel shadows and square pixel cards.** The brand's signature, shared with the website.
2. **Display weight 800 (Bricolage ExtraBold) on titles.** Catalog caps at 600; this is the display face.
3. **Hoot idles with a loop in the sidebar and About page.** It is the mascot, not chrome, and it stops under Reduce Motion.
4. **Native controls** (the font menu, the open panel) keep system styling; only our own controls are themed.

## Motion rules for anything new
transform/opacity only, 100/150/200/300 ms, ease-out in, ease-in out, no bounce, honor Reduce Motion
(`accessibilityDisplayShouldReduceMotion`). Meaning is never carried by motion alone.
